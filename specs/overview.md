# Product Overview

## Summary

**Quick Bookmark** is a cross-browser extension that lets users add the
current tab to (or remove it from) any bookmark folder with as few
keystrokes as possible. It provides a spotlight-like fuzzy-search popup
with full mouse and keyboard support, including Chinese pinyin search.

- Manifest version: 1.3.9 (Manifest V3)
- Homepage: https://github.com/fffx/quick-bookmark
- Chrome Web Store: https://chrome.google.com/webstore/detail/quick-bookmark/bbjekmkfbdemdbfkckbakmmiceppjkdc
- License: MIT
- Origin: React port of [chrome-better-bookmark](https://github.com/ardcore/chrome-better-bookmark),
  built on [web-extension-starter](https://github.com/abhijithvijayan/web-extension-starter)

## Supported Browsers

| Browser | Support | Notes |
| --- | --- | --- |
| Chrome | Yes | minimum Chrome 88; background runs as a service worker |
| Firefox | Yes | stable gecko id `{754FB1AD-CC3B-4856-B6A0-7786F8CA9D17}`; background runs as a persistent script |
| Opera | Yes | minimum Opera 36; packaged as `.crx` |
| Edge | Yes (build target) | shares the Chrome service-worker manifest flavor |

Browser differences are handled at build time via `__<browser>__`-prefixed
manifest keys (processed by `wext-manifest-loader`) and at runtime via UA
sniffing in `source/lib/browser.ts`.

## Activation

- Keyboard shortcut (Manifest `commands._execute_action`):
  - Chrome: `Ctrl+B` (Windows/Linux/ChromeOS), `Command+B` (macOS)
  - Firefox: `Ctrl+B`, `Alt+B` on macOS
  - User-rebindable at `chrome://extensions/shortcuts`
- Clicking the toolbar icon.

## Core Features

1. **Bookmark / un-bookmark the current tab into any folder**
   - One click (or `Enter`) on a folder saves the current tab into it.
   - If the folder already contains the current tab (URL compared with the
     `#fragment` stripped), the same action removes the bookmark instead.
2. **Spotlight-like fuzzy search** over folder names and full folder paths
   (powered by Fuse.js), with a 150 ms debounce on input.
3. **Create folders on the fly**
   - Typing a new name offers "create folder" entries under each root node.
   - Path syntax `parent / child` offers to create `child` inside the
     matched `parent` folder(s), and immediately bookmarks the tab into it.
4. **Chinese pinyin search**
   - Enabled only when a `zh*` language appears in `navigator.languages`
     and `tiny-pinyin` reports support; pinyin fields are indexed for both
     full pinyin and first-letter (acronym) search.
5. **Folders containing the current tab sort first** and are shown in bold
   with a red "remove" icon. When the tab is not bookmarked yet, folders
   are ranked by URL/keyword match: same origin/host, folder title
   matching a token from the tab URL (e.g. `java.com` → folder `java`),
   or a child bookmark whose URL/title contains that token (e.g. folder
   `programming` with `javablog.com`); remaining folders sort by
   `dateGroupModified` descending.
6. **Toolbar badge** showing how many bookmarks point at the current tab's
   URL, updated live on tab/navigation/bookmark events.
7. **Domain-only save**: holding `Alt` while confirming saves just
   `protocol://hostname` with the hostname as the title.
8. **Keyboard navigation**: `ArrowUp`/`ArrowDown` move the selection (with
   wrap-around), `Enter`/`Delete` activate the selected row; the list
   scrolls the focused row into view.

## Permissions

Declared in `source/manifest.json`:

- `bookmarks` — read the tree, create/remove bookmarks and folders.
- `tabs` — query the active tab's URL/title.

CSP: `script-src 'self'; object-src 'self'` for extension pages.

## Non-Goals / Current Limitations

- The Options page (`views/options.html`) is generated by the build but has
  no bundled script; there is no user-configurable settings UI.
- No bookmark editing, reordering, or multi-tab bulk operations.
- No sync of extension state itself (relies on the browser's bookmark sync).
